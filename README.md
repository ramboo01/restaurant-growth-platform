# RestruRent

RestruRent is a production-level Restaurant Growth Platform foundation.

## Confirmed Tech Stack

- Frontend: React.js
- Backend: Node.js
- Database: MySQL

## Project Structure

```text
restrurent/
  frontend/
  backend/
```

## Run Instructions

Install dependencies:

```bash
npm run install:all
```

Start the frontend:

```bash
npm run start:frontend
```

Start the backend:

```bash
npm run start:backend
```

The MySQL schema, authentication, dashboards, and business modules are intentionally not configured in this foundation step.
